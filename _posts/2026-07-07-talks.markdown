# First talk

## Unlocked and leaked

### Speaker

Darren ([r3n5k1](https://twitter.com/r3n5k1)) and Craig ([@craigsblackie](https://twitter.com/craigsblackie))

### Synopsis

The BIOS password is often seen as the first line of defence against all kinds of attacks and commonly involved in bypassing full disk encryption. In this talk we go over four different methods of circumventing this protection in modern Dell UEFI. Covering clearing the passwords, modifying the SPI flash DMA security settings to appear on when they are off, the "just ask nicely" approach, and a novel technique being discussed publicly for the first time which allows clear text extraction of passwords.

You may see this referenced as CVE-2026-40639.

Slides: [https://github.com/R3n5k1/unlocked-and-leaked](https://github.com/R3n5k1/unlocked-and-leaked)

# Second Talk

## When Your Coding Agent Gets Pwned

### Speaker

Zen Van Riel, [Apollo Research](https://watcher.apolloresearch.ai/landing/) ([LinkedIn](https://uk.linkedin.com/in/zen-van-riel))

### Synopsis

AI coding agents now write and execute code autonomously - running shell
commands, accessing external endpoints, editing config files. That's a
massive attack surface. We'd walk through real failure modes (prompt
injection, data exfiltration, instruction violations) and do a live demo of
a prompt injection attack against Claude Code. And we'd show how why
runtime guardrails are important in catching this.

About us: We're a technical AI safety company: our research team works
with frontier labs (OpenAI, Anthropic, Google DeepMind) on pre-deployment
model evaluations and safety research. On the product side, we've built
Watcher, a runtime monitoring layer that sits on top of coding agents like
Claude Code and Cursor (think an MDM/EDR for AI agents); detecting prompt
injection, data exfiltration, policy violations, and malicious behaviour in
real time.
